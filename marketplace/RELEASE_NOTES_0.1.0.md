# VPS Graph 0.1.0

VPS Graph 0.1.0 is the initial public beta of a local-first, read-only infrastructure explorer for one Linux VPS.

Source: [github.com/cemililkim/vps-graph](https://github.com/cemililkim/vps-graph). A direct helper archive link will be added only with the matching GitHub Release.

It includes manual public-key SSH discovery, Docker and Compose application views, Caddy routing relationships, Systemd services, host listeners, local snapshots, Changes history, remembered safe connection fields, setup guidance, and local Disconnect.

The optional server helper uses one exact argument-free sudo command and returns only allowlisted infrastructure metadata. VPS Graph has no account, backend, telemetry, cloud sync, or remote management controls.

Current limitations include IntelliJ IDEA build 251.* only, one active server, Debian/Ubuntu-focused discovery, manual scans, and no SSH password, agent, passphrase, OpenSSH config, ProxyJump, or bastion support.
