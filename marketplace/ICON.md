# Plugin icon gate

**FINAL ICON REQUIRED**

No approved VPS Graph icon exists in this repository. R3 deliberately does not generate or substitute a generic mark.

The final JetBrains plugin icon should be added at `intellij-plugin/src/main/resources/META-INF/pluginIcon.svg`, with `pluginIcon_dark.svg` only if a separate dark-theme treatment is needed. It must be a square SVG that remains legible at small Tool Window and Marketplace sizes and contains no remote resources, raster links, text that becomes unreadable, or personal infrastructure data.

This checkout contains no authoritative local copy of the current Marketplace dimension and file-size requirements. The publisher must verify the final SVG against the JetBrains Marketplace submission validator and current official requirements before publication.
